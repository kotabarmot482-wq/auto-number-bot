# AUTO NUMBER BOT — новый проект

Новый оригинальный Telegram Mini App-прототип в тёмном автомобильном стиле.

## Что уже работает в демо
- Выбор страны: Беларусь, Россия, Украина.
- Случайная прокрутка номера внутри выбранной страны.
- Игровые рубли, энергия, опыт и локальное сохранение.
- Категории редкости и демонстрационная оценка найденных номеров.
- Гараж и фильтр по редкости.
- Магазин косметических номерных рамок с предпросмотром.
- Рамки покупаются отдельно от номеров; не дают бонусов и не имеют игровой ценности.
- Задания, демонстрационный рейтинг, друзья и профиль.
- Адаптивный интерфейс и базовая интеграция Telegram WebApp.

## Запуск
Открой `index.html` в браузере или размести все четыре файла в корне GitHub Pages.

## Важно: это прототип, не готовый многопользовательский сервис
Сейчас данные хранятся в `localStorage` браузера. У разных игроков нет общей базы, рейтинг и приглашения демонстрационные. Для полноценного запуска потребуется отдельный сервер, база данных, проверка Telegram WebApp `initData`, API и безопасное хранение токена Telegram-бота на сервере.

Не вставляй токен бота в `app.js`, `index.html` или другие публичные файлы. Если токен ранее публиковался, отзови его через BotFather и выпусти новый.
