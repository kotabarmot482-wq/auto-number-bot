# AUTO NUMBER BOT — версия 2

## Что внутри
- Обновлённый мобильный интерфейс в тёмном стиле с золотыми акцентами.
- Главная страница с выбором Беларуси, России и Украины.
- Демогенератор игровых номерных комбинаций и уровней редкости.
- Игровые рубли (₽), гараж, рейтинг-макет, задания и реферальный экран.
- Telegram WebApp SDK подключён.

## Публикация на GitHub Pages
1. Распакуйте архив.
2. Замените в корне репозитория GitHub Pages файлы `index.html`, `style.css`, `app.js`.
3. Подтвердите Commit changes и подождите обновления Pages.

## Важно: это фронтенд-демоверсия
- Баланс, коллекция и задания пока хранятся только в оперативном состоянии страницы; при перезагрузке они сбрасываются.
- Рейтинг, приглашения и реферальные начисления пока демонстрационные. Для настоящей работы нужны сервер, база данных и проверка Telegram initData.
- Форматы номеров являются игровыми макетами, не официальными документами; перед релизом нужно отдельно сверить актуальные региональные форматы и правила каждой страны.
- Не размещайте токен Telegram-бота в этих файлах. Храните его только в секретах серверного окружения.
