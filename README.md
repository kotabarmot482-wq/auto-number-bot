# AUTO NUMBER BOT — Telegram Mini App

В проекте есть:
- выбор страны: Беларусь, Россия, Украина;
- генератор номерных знаков и коллекция;
- шесть уровней редкости;
- четыре тарифа прокрутки;
- виртуальная экономика без реальных денежных ставок;
- колесо удачи с серверным ограничением 24 часа;
- рамки аватара;
- профиль и правила игры.

## Важно
Форматы номеров в текущей версии — игровые шаблоны, а не официальный реестр выданных регистрационных знаков. Не используйте их для проверки реальных автомобилей.

## 1. Что понадобится
- Node.js 20 или новее;
- Telegram-бот, созданный через @BotFather;
- HTTPS-адрес для размещения Mini App;
- переменная окружения `BOT_TOKEN` на сервере.

Не отправляйте токен бота в чат и не добавляйте его в GitHub. Если токен когда-либо публиковался, перевыпустите его через BotFather.

## 2. Запуск на компьютере
```bash
npm install
cp .env.example .env
```
Откройте `.env` и вставьте новый токен в `BOT_TOKEN`. Затем:
```bash
npm start
```
Откройте `http://localhost:3000`. В обычном браузере интерфейс работает в демо-режиме с локальным балансом. Для серверной экономики Mini App нужно открыть через Telegram и настроить HTTPS.

## 3. Размещение
Разместите весь проект на Node.js-хостинге, который поддерживает постоянный процесс и хранение файла SQLite. Установите переменные:
- `BOT_TOKEN` — токен бота (только в секретах хостинга);
- `PORT` — порт, который выдаёт хостинг.

Папка `data/` содержит базу SQLite. Подключите постоянный диск/volume, иначе данные могут сбрасываться при перезапуске или redeploy.

## 4. Подключение к Telegram
В @BotFather:
1. Выберите своего бота `@neoautonumb_bot`.
2. Откройте настройки Mini App / Web App и задайте HTTPS URL приложения.
3. Настройте кнопку меню на открытие Web App.
4. Проверьте, что приложение открывается именно внутри Telegram.

Бэкенд проверяет подпись `initData` Telegram перед изменением баланса, прокруткой и колесом. Не отключайте эту проверку в опубликованной версии.

## 5. Ограничения текущего прототипа
- Рамки и профиль пока демонстрационные; покупка рамок и синхронизация экипировки ещё не подключены к API.
- Нет админ-панели и полноценной системы заданий/друзей.
- Рейтинг сейчас отдаёт данные API, но отдельный экран рейтинга ещё не сделан.
- Призы колеса и шансы редкости можно настроить в `server/index.js`.
- Номерные шаблоны игровых регионов следует расширить и проверить перед релизом.

## 6. Файлы
- `public/` — интерфейс Mini App;
- `server/index.js` — API, Telegram auth, SQLite и серверная логика;
- `.env.example` — пример секретов;
- `package.json` — зависимости и запуск.
