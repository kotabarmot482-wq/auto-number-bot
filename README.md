# BELARUS NUMBER RUSH

Telegram Mini App — виртуальный симулятор коллекционирования автомобильных номерных знаков в стиле казино.

## Важно
Все рубли в проекте — **виртуальные игровые очки**. Нет денежных ставок, покупки игровой валюты или вывода выигрышей. Номера — игровые стилизованные комбинации, не предназначенные для использования на реальных автомобилях.

## Что уже реализовано
- Стартовый баланс нового игрока: 10 000 000 виртуальных рублей.
- Пять категорий прокрутки с заданной стоимостью.
- Анимированная прокрутка символов.
- Стилизация номерного знака, вспышка и эффекты.
- Случайная цена продажи в диапазоне выбранной категории.
- Коллекция, продажа номера и история выпадений.
- SQLite для сохранения баланса и коллекции.
- Telegram Web App: проверка `initData` на сервере.
- Команда `/start` и кнопка открытия Mini App.

## Локальный запуск
Нужен Node.js 20 или новее.

1. Распакуй архив.
2. В терминале в папке проекта выполни `npm install`.
3. Скопируй `.env.example` в `.env`.
4. Для локального теста укажи `DEMO_MODE=true`.
5. Выполни `npm start`.
6. Открой `http://localhost:3000/?demo=1`.

Демо-режим предназначен только для локальной проверки. Не включай его на публичном хостинге.

## Подключение Telegram
1. Создай HTTPS-сайт на хостинге.
2. Укажи его адрес в `WEBAPP_URL`.
3. Укажи токен бота в `BOT_TOKEN` как переменную окружения хостинга. Не добавляй токен в GitHub и не отправляй его в чат.
4. Установи `DEMO_MODE=false`.
5. Перезапусти сервер.
6. Открой чат с ботом и отправь `/start`.
7. Если у бота уже есть старая кнопка меню, замени её URL на новый HTTPS-адрес Mini App через настройки BotFather.

## Размещение
Проект рассчитан на Node.js-хостинг с постоянным диском, потому что SQLite хранится в `data/game.sqlite`. Если хостинг удаляет локальные файлы при перезапуске или не предоставляет persistent disk, прогресс может потеряться — подключи постоянный диск или внешнюю базу данных.

## Правила редкости
В этой стартовой версии игрок выбирает категорию прокрутки. Выпавший номер получает комбинацию символов в стиле выбранной категории, а цена продажи случайно выбирается в установленном диапазоне. Для публичного запуска стоит дополнительно настроить вероятности выпадения и защиту от злоупотреблений.
