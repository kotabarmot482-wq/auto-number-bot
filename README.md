# AUTO NUMBER BOT — Mini App starter

## Что уже работает
- Адаптивный интерфейс в чёрно-золотом стиле
- Выбор страны: Беларусь, Россия, Украина
- Демонстрационная генерация комбинаций
- Локальная коллекция номеров
- Демонстрационные задания, баланс ANB и косметический магазин
- Чтение базовых данных пользователя Telegram Web App

## Важно
Это стартовый фронтенд-прототип. Баланс, коллекция и задания хранятся локально в браузере и не защищены от изменения пользователем. Не используй их для реальных платежей или ценных призов. Для общего рейтинга и постоянного хранения нужен сервер и проверка `Telegram.WebApp.initData` на сервере.

Генератор пока демонстрационный: перед публичным запуском нужно отдельно проверить и уточнить допустимые форматы и региональные коды каждой страны.

## Локальный просмотр
Открой `frontend/index.html` в браузере. Для полноценного Telegram Mini App страница должна быть размещена по HTTPS, затем URL подключается в BotFather через настройки Web App.

## Следующий этап
1. Разместить frontend на HTTPS-хостинге.
2. Подключить URL к кнопке меню бота через BotFather.
3. Сделать Node.js backend.
4. Подключить базу данных и серверную проверку Telegram initData.
